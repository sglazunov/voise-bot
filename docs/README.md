## Одним абзацем

**linux-voise** — это сервис, который превращает встречи в готовые текстовые
протоколы **без ручной работы**. Человек либо загружает запись сам, либо система
сама заходит ботом на встречу в Яндекс.Телемосте (по задаче из трекера Weeek),
записывает её, распознаёт речь, определяет, кто говорил (по видео), и собирает
аккуратный документ Word с решениями, задачами и ответственными — а ссылку кладёт
обратно в задачу. Всё разворачивается одной командой через Docker.
